02 · 제안 방식

3단 필터 — 1차 메타데이터 · 2차 AI · 3차 관리자

1차 · 메타데이터 필터  PII + 사전(키워드)
① PII 검출 — ko-pii 20종(주민·카드·계좌·여권·주소 …), 대량 검출 시 상향
② 결합식별성(COMBO) — 주민+계좌 → C, 전화·메일·주소 2종+ → S
③ 기밀사전 키워드 — 대외비·극비 등, 본문·파일명 공통
④ 법상 민감정보 — 건강·유전·사상·노조·범죄경력 → C
⑤ 보안분류 스탬프 — 머리 400자 또는 2회 이상 반복일 때만 인정
⑥ 경로 · 파일명 — 본문을 열지 않는 값싼 출처 신호
→ 5종 신호를 보수적 max 융합(가장 민감한 등급 채택)
빠르고 값싸다 · 근거가 남는다  →  실측 226건(56%) 확정
›
2차 · AI 필터  문맥(벡터) 비교
룰은 "쓰여 있는 것" 만 잡는다. 표현·양식이 달라 안 걸린 문서를 구제하는 단계.

· 1차 보류(none) 문서만 벡터화
· e5-small-ko 384차원 int8 소형 모델
· Seed 문서와 코사인 유사도 비교 → 임계 이상이면 등급 전파
· 룰로 확정된 고신뢰 문서는 Seed 로 자동 승격 (Seed 0건에서도 시작 가능)

안전장치 — 임베딩은 보조 신호일 뿐, 1차 확정 등급을 뒤집지 않는다
전 문서 아닌 41.6%만 임베딩  →  64건(16%) 구제

특이사항 — 압축파일(ZIP) 처리

ZIP 은 그 자체로 아무 내용이 없다. 출처기반은 압축 해제 시 출처가 소실되고, 문맥기반은 열지 못한다 — 실무 최대 사각지대.

  • 내부 파일을 풀어 하나하나 개별 분류 (중첩 압축 재귀)
  • 결과에 "압축경로/내부경로" 표기 → 어느 파일이 C 인지 특정
  • 압축 자체 등급 = 내부 최고 위험등급 롤업 · 처리 후 임시폴더 자동 삭제

04 · 검토사항

검토사항 5가지 — 결정이 필요합니다

① 품질 측정 방안

현재 정답셋(ground truth)이 없다. "몇 건이 분류됐나"는 알지만 "맞는가"는 미측정. 단순 정확도는 무의미 — 어느 방향으로 틀렸는지가 중요:
과소분류 C·S→O = 유출 직결   과대분류 O→C·S = 업무 마비

방안 층화 표본 200~300건 교차 라벨링 · 3차 오버라이드 로그를 정답으로 축적 · 회귀 테스트셋 고정

목표(안) C 재현율 ≥95% · 과대분류 ≤10% · 보류율 ≤15%(현 24.9%)

② 배포 크기 — 266MB

모델 129MB · 파이썬 런타임 108MB · 사이냅+본체 15MB

엔드포인트 대량 배포 시 부담. 망분리 환경 업데이트 채널도 고려 필요.

경감 방안
· --rule-only 전용 = 약 137MB (2차 AI 포기)
· 2차 AI 는 중앙 서버, 엔드포인트는 룰만 권장
· 모델만 별도 채널로 1회 배포 후 공유

③ 실시간 속도

일반 문서(10p) 0.12~0.4초 가능
581p PDF 7.5초 · ZIP 16.5초 불가
콜드 스타트 +2.4초 데몬 필수

배치(야간 전수)는 문제없다. 반출·저장 시점 동기 차단은 체감 지연 발생.

권장 데몬 상주 · 임계 초과분은 비동기 큐 · 압축은 즉시 차단 후 사후 분류 · 해시 캐시로 재검사 회피

④ 스캔·이미지 (OCR 부재)

본문 텍스트를 읽어 판정하므로 텍스트 없는 문서는 구조적으로 검출 불가. 스캔 PDF · 첨부 이미지 · jpg/png — 정작 가장 민감한 서류가 여기 많다.

실제 사례 (신규)문서중앙화 제품소개-1.pdf — 6.7MB · 44페이지인데 추출 텍스트 35자 → 미분류

대응 ① 글자수 임계 미만 시 "OCR 필요" 플래그 → 3차 큐 우선 이관 ② 선택적 OCR 연동(속도·용량 재검토) ③ 추출 실패 시 기본등급 S 강제 여부

⑤ 라이선스 확인 — 사이냅 + 오픈소스 모듈

상용 사이냅 문서필터 snf_exe·snf_win.dll
실측 결과 라이선스 키가 바이너리에 임베드돼 있어 배포 시 키도 함께 나간다. → 배포 전 사이냅과 재배포 조건(시험판·기간제한) 확인 필수

LGPL-2.1+ 독점(RAR) 압축 해제 — py7zr 소스 제공 의무, unrar 독점 포맷 재배포 조건 검토. 7z·rar 미지원 결정 시 둘 다 제거 가능

확인 필요 임베딩 모델 e5-small-ko — 가중치 라이선스·상용 재배포 가능 여부

MIT·BSD·Apache 그 외 전부 제약 없음 — onnxruntime·ko-pii·PyYAML·tokenizers·numpy·olefile·xlrd·pypdfium2. PyInstaller 는 GPLv2 + 번들 예외라 산출물에 영향 없음

이미 회피한 것 — HWP·OOXML 파서를 자체 구현해 pyhwp(AGPL) 등 까다로운 의존을 처음부터 배제
