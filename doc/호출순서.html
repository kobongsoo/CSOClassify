MpowerClassify — 함수 호출 순서

명령 한 줄이 어떤 함수들을 거쳐 임베딩 벡터가 되는지 (기본: 데몬 on)

MpowerClassify.exe -file {파일}
클라이언트 프로세스 데몬 프로세스(상주) 공통 파이프라인 청킹 입출력

◎ 청킹 기본값과 실제 적용값

# config.py — 기본값(‑‑max-tokens / ‑‑overlap 로 재정의 가능)
DEFAULT_MAX_TOKENS = 256      # 청크 최대 토큰
DEFAULT_OVERLAP    = 32       # 겹침 토큰
ModelSpec.max_tokens_model = 512   # e5-small-ko 모델 상한

# _split_chunks 실제 계산 (onnx_embedder.py:148~152)
hard_cap    = min(256, 512) = 256
effective   = max(8, 256 - prefix_len(~4) - 2) ≈ 250 토큰   # "passage: "+특수토큰 자리 제외
eff_overlap = min(32, effective-1) = 32 토큰

→ 본문을 약 250토큰씩·32토큰 겹침으로 자름. 출력은 첫 청크가 아니라 전 청크의 평균 벡터(문서 대표). 청크별로 보려면 --per-chunk.
