# 1차 측정 — 분류·PII 를 포함한 비교 (2026-09-11 오전)

자체판을 `--rule-only` 로 돌려 **추출 + 규칙/PII 분류까지** 한 시간을 쟀고,
사이냅이 뽑은 본문을 같은 분류기에 다시 넣어 **최종 보안등급이 갈리는지**까지 봤다.

지금의 보고서(`report/파서비교-자체파서-vs-사이냅-202609.html`)는 그 뒤에 다시 잰
**순수 파서** 비교판이라, 이 폴더의 스크립트로는 만들어지지 않는다.
등급·PII 일치율을 다시 보고 싶을 때만 쓴다.

| 지표 | 1차 결과 |
|---|---|
| 보안등급 일치율 | 98.4% (305건 중 5건 불일치) |
| PII 유형 집합 일치율 | 96.8% |
| 불일치 5건 | 4건은 자체판이 더 많이 검출 · 1건은 사이냅 본문 쪽 오탐("발전과"→"전과") |

실행 순서: `run_bench.py` → `harvest.py` → `overhead.py` → `final_stats.py`
(`final.json` 이 그 결과다).
